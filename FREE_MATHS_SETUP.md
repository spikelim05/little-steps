# Free maths revision links

Run all of `supabase/free-maths.sql` in Supabase SQL Editor, then refresh the website (students already signed in can reload). This replaces the Home Campus and IXL entries for both students and adds six free online activities. It preserves their science resources, other custom resources, exam dates and recorded scores. It is safe to rerun.

The new activities have new IDs, so old completion ticks do not incorrectly mark them as already tried. Historical challenge scores remain. Tasks already written in Give guidance are not changed; edit any such task if you previously sent a paid link.

Checked 3 October 2026 using the provider's public activity pages and its [free resources page](https://www.mathmammoth.com/free/). These online activities are free; optional workbooks are separate purchases. JavaScript and internet access are required. Provider grade labels differ from Singapore levels, so the app includes topic-based instructions and suggested settings.

| Activity | Topic |
| --- | --- |
| [Money estimation](https://www.mathmammoth.com/practice/estimating-money) | Estimate totals, change and quantities; original follow-up task asks for exact calculations |
| [Decimal hidden picture](https://www.mathmammoth.com/practice/mystery-picture-decimals) | Addition and subtraction; select two decimal places |
| [Find factors](https://www.mathmammoth.com/practice/factorfind) | All factors and factor pairs |
| [Fraction practice](https://www.mathmammoth.com/practice/add-subtract-fractions) | Configurable addition and subtraction |
| [Angle matching](https://www.mathmammoth.com/practice/angles-matching) | Estimate angle measures in different orientations |
| [Area builder](https://www.mathmammoth.com/practice/area-builder) | Explore area and perimeter; PhET simulation hosted on Math Mammoth |

These are topic practice activities, not complete Singapore exam papers. The tasks in Little Steps are original prompts; the provider's questions are linked, not copied. External results do not automatically sync to Little Steps.
